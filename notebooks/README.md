# Notebooks

This directory is split by purpose.

## `paper/` — published results

The notebooks that generate every figure and table in the
[JCIM 2025 paper](https://doi.org/10.1021/acs.jcim.5c00475). Numbered in the
order they should be run. **Start at
[`paper/README.md`](paper/README.md)** — it documents the pipeline that
produces the notebooks' inputs, which are not in the repository.

These are the notebooks to use if you want to reproduce the paper.

## `exploratory/` — ongoing work

Scratch analyses, in-progress experiments, and the runnable tutorials. Not part
of the published results, no stability guarantees, and they may break or change
without notice.

| Notebook | What it is |
|---|---|
| `colab_splitter_quickstart.ipynb` | Colab-ready tour of the splitter API — no local install needed |
| `example.ipynb` | Walkthrough of the splitting and analysis API on a real dataset |
| `dev.ipynb` | Author's scratchpad |

The first two are also rendered, with narration, in the
[Tutorials section of the documentation](https://hfooladi.github.io/ALineMol/tutorials/).
